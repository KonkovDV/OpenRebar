# P0-6 — workflow CI не стартует

Дата: 2026-10-02.

## Диагноз

Прогоны `ci.yml` с `e5669ee` по `4511130` имеют 0 job. `16b5e91` (run `36911012627`) создал 3 job. `actionlint` 1.7.12 на файле из `e5669ee` указывает строку:

`run: echo "corpus: NotEvaluated" >> "$GITHUB_STEP_SUMMARY"`

Кавычки здесь не строка YAML: значение начинается с `echo`. Последовательность `: ` YAML читает как ключ отображения, файл не разбирается, GitHub не создаёт job.

Та же фраза внутри `run: |` в `benchmark-corpus` уже была блочным скаляром и ошибкой не была.

## Правка

Шаг `corpus-note` пишет фразу блочным скаляром. Job `lint-workflows` качает actionlint 1.7.12 по SHA-256 `8aca8db9…` и проверяет все workflow.

## Приёмка

`actionlint` на `.github/workflows/*.yml` без ошибок. На GitHub job появятся только после пуша; локально это не видно.
