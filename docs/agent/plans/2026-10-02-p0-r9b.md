# P0-r9b — торец не на грани бетона

Дата: 2026-10-02.

Правки триажа из `files/triage.patch` уже в дереве и проходят 389/389. Эта задача — RT-1 из r9.

## Правило

Свободный край рабочей области отступает на `max(coverEdgeMm, coverMm + d/2)` для диаметра стержня этой зоны. Опора и непрерывный край по-прежнему выходят наружу на `max(0, supportDepthMm − coverEdgeMm)` и этим отступом не режутся.

Если `coverEdgeMm < coverMm`, в отчёт пишется `EdgeCoverBelowCover`. Умолчание края остаётся Free, зачёт крюка 0, П-образные стержни не генерируются.

## Почему не 6505,5 мм

Оценка в r9 вычла из пролёта два раза по 30 мм (только `cover`) и получила 5940 мм, длину 6505,5 мм и массу 433,85 кг. Записанное правило для Ø20 — `30 + 20/2 = 40` мм с каждого свободного края. Прогон `simple-slab`:

- 27 стержней, прямой участок 5920 мм, развёртка 175 108,14 мм (5920 + 2·π·90).
- Масса по точной длине 432,517 кг. В ведомости длина округлена до 6485 мм, масса позиций 432,485 кг, дрейф 0,032 кг — тот же порядок округления, что был у 437,852 против 437,820.
- Закупка 600,21 кг не изменилась: кусок 6485 мм по-прежнему один пруток 9000. Отход 27,02% → 27,91%, потому что уложенной стали меньше, а пруток тот же.
- Недобор 6,8 → 7,11 м². Из них развитие у свободного торца 6,12 м² (было 6,8: ячейки на самой грани больше не содержат стержень). Реальный дефицит 0 → 0,99 м²: полосы защитного слоя по торцам и по длинным сторонам входят в проверяемую площадь, а оси там нет.
- Статус по-прежнему Failed, код выхода 2. Добавлено предупреждение `EdgeCoverBelowCover`.

Крюк радиусом 90 мм при отступе 40 мм всё ещё выходит за грань. Его кривую в бетон кладёт отдельная задача.

Rbt для B55/B60 не менять.
