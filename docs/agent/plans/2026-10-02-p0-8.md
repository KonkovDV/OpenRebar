# P0-8 — Dependency Review на PR #118

Дата: 2026-10-02.

## Диагноз

Прогон `36974908905` падает не из‑за лицензии и не из‑за advisory. Строка в логе:

`Dependency review is not supported on this repository. Please ensure that Dependency graph is enabled`

Граф зависимостей в репозитории выключен. `allow-licenses` / `deny-licenses` тут ни при чём.

PR #118 — патч `Microsoft.Extensions.*` 10.0.7 → 10.0.12 (DependencyInjection, Logging, Logging.Abstractions, Logging.Console). ImageSharp и FluentAssertions он не трогает.

## Правка

Включить dependency graph. Для этого API включает vulnerability alerts: отдельного переключателя графа в ответе репозитория нет. Dependabot security updates остаются выключенными.

Обновление ветки #118 на `main` склеило `packages.lock.json` так, что у Application, Infrastructure и Domain в замке остался один TFM. Из-за этого `dotnet restore --locked-mode` падает с NU1004. Замки пересобраны. Revit тоже на 10.0.12, иначе плагин остаётся на 10.0.7 рядом с библиотеками 10.0.12.

После зелёного `build-and-test` и `dependency-review` PR можно мержить. `allow-licenses` не нужен.

## Что не делать

Не ослаблять порог `fail-on-severity`. Не добавлять allow-list лицензий под эту ошибку.
